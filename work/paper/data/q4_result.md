# 2025-C 问题 4 结果（女胎异常判定）— 去重稳健性修正版

> 运行：`work/solve/c_q4.py`（评审 P2 修正：按孕妇去重稳健性 + 外部证据）
> 数据：女胎 604 行 / 147 位孕妇（44 异常按孕妇级）

## 方法对比

| 方法 | recall | precision | 说明 |
|---|---|---|---|
| 逻辑回归（14 特征，thr=0.5） | 0% | - | 类别不平衡（11% 异常）|
| 逻辑回归（thr=0.15） | 11.9% | 12.3% | 阈值下调仍弱 |
| 经典 Z>3 阈值 | 4.5% | 7.1% | Z 值法在此数据失效 |
| **X 浓度 ≤ -0.02（行级）** | 55.2% | 28.0% | 主判据 |
| **X 浓度 ≤ -0.02（孕妇去重）** | **52.3%** | **56.1%** | **稳健（precision 大幅提升）**|
| X 浓度 ≤ -0.01（孕妇去重） | 79.5% | 46.7% | 高敏 |

## 关键发现

1. **X 染色体浓度是女胎异常最强判据**（r=-0.319 行级；去重后 precision 从 28%→56%）
2. **按孕妇去重消除重复行稀释**——同一孕妇多次检测在行级评估中重复计数，去重后判别更真实
3. **分型**：T18（x_conc 均值 -0.0258）、T13（-0.0227）显著低于正常（-0.0049）；T21（-0.0123）较弱——X 浓度降低与 X 连锁异常（T18/T13）更相关
4. **Z 值（13/18/21/X）判别力弱**——异常/正常均值接近，单靠 Z 值不足
5. GC 含量（gc13 r=0.108）有辅助判别力

## 建议判定方法

```
女胎异常判定（孕妇级）：
  x_conc ≤ -0.02 → 疑似异常（precision 56%，重点复查 T18/T13）
  x_conc ≤ -0.01 → 高敏筛查（recall 80%，配合 GC13 辅助）
  辅助：z13/z18/z21 > 3（低召回，仅补充，因 Z 值法在此数据 PPV 低）
```

## 外部证据

- **ACMG 2022 guideline**：NIPS 对 T21 的 PPV 仅 50-95%，1.1-2 例羊穿确认 1 例——单靠 Z 值不足，需结合多特征/临床因素。https://www.sciencedirect.com/science/article/pii/S1098360022010048
- **性别机制**：男胎 fetal fraction 高于女胎（ScienceDirect 2022）→ 女胎无 Y 信号，X 浓度成为主要判别维度，支持本研究"女胎用 X 浓度"的方法选择。https://www.sciencedirect.com/science/article/pii/S0890850822000810

## 数据注记

- AB 异常（67 行/44 孕妇）与"健康"列全"是"矛盾——AB 是检测标记（含假阳），健康是出生结果
- 按孕妇去重后异常 44/147（29.9% 孕妇级）——高于行级 11.1%，因异常孕妇多次检测
- 建议按类型分型建模（T18/T13 用 X 浓度，T21 需其他特征）
