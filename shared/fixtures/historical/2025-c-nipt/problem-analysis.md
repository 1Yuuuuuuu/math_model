## 问题 1：Y 染色体浓度与孕周、BMI 的相关性与关系模型

**目标**：建立 Y 浓度 ~ 孕周 + BMI 的关系模型，检验显著性。
**数据**：男胎 sheet（孕周 J、BMI K、Y 浓度 V，950 记录/260 孕妇）。
**方法**（评审修正）：
- **线性混合效应模型**（孕妇随机截距）处理重复测量：`y_conc ~ week + bmi + (1|mother)`
- 相关分析（按孕妇聚合去重复）
- 显著性检验（混合效应 p 值 + ICC）
- 对照简单 OLS（显示重复测量影响）
**工具**：`linear-regression`、`correlation-analysis` + statsmodels MixedLM
**外部证据**：Deng 2023（153,306 例，BMI 负相关）；ScienceDirect 2022（孕周增长、男胎更高）
**产物**：混合效应系数/ICC、聚合相关、显著性报告

## 问题 2：男胎 BMI 分组与最佳 NIPT 时点

**目标**：按 BMI 分组，求每组 Y 浓度达标（≥4%）的最早时间 → 最佳 NIPT 时点 → 风险最小化 + 误差分析。
**数据**：男胎（BMI、孕周、Y 浓度；纵向序列）。
**方法**（评审修正）：
- **K-means 聚类分组**（数据驱动，替代固定区间；肘部法则 + 题意选 k=5）
- 每孕妇达标孕周（纵向最早 Y≥4%）
- 每组 P90 达标周 + **90% bootstrap 置信区间**
- 风险分级（<13w 低 / 13-27w 高 / >28w 极高）+ 未达标复测
- 误差扰动（±5%/±10%）
**工具**：`kmeans`、`interpolation`（若需）、`confidence-interval`
**外部证据**：K-means + 多目标风险优化的 NIPT 时点方法（Semantic Scholar）
**产物**：聚类分组表、每组时点 + CI、风险对比、误差影响

## 问题 3：多因素综合的 BMI 分组与时点优化

**目标**：综合身高/体重/年龄等 + 检测误差 + 达标比例 → BMI 分组 + 最佳时点。
**数据**：男胎（年龄、身高、体重、BMI、孕周、Y 浓度、健康）。
**方法**（评审修正）：
- **混合效应**（孕妇随机截距）多因素：`y_conc ~ week + bmi + height + (1|mother)`
- 共线性诊断（weight~bmi 0.827 → 不共入）
- 控制 BMI 后残差相关（height 独立增量）
- **K-means 分组** + 达标/健康比例 + P90 时点
- 误差影响
**工具**：`linear-regression`、`correlation-analysis` + MixedLM、`kmeans`
**外部证据**：Deng 2023（maternal weight/height 因素）
**产物**：多因素混合效应、分组时点、达标比例、误差分析

## 问题 4：女胎异常判定方法

**目标**：以 AB 列（非整倍体）为判定结果，综合 X 染色体、13/18/21 号 Z 值、GC 含量、读段数、BMI → 分类器。
**数据**：女胎（604 行/147 孕妇，44 异常孕妇级）。
**方法**（评审修正）：
- **按孕妇去重**的稳健性评估（消除重复行稀释）
- 特征：X 浓度（主判据）、Z 值、GC、读段、BMI
- **X 浓度阈值判定**（主方法）+ 逻辑回归（对照）+ Z>3 经典法（对照）
- 按异常类型分型（T13/T18/T21）
**工具**：`logistic-regression`、`correlation-analysis`
**外部证据**：ACMG 2022（Z 值 PPV 局限）；ScienceDirect 2022（性别机制→女胎用 X 浓度）
**产物**：判定方法（X 浓度阈值）、评估矩阵、分型差异、与 Z 值法对比

## 风险与注记

- Y 浓度多列单位：V 列是比例（0.04=4%），注意数值尺度
- 孕周格式 `13w+5` 需解析为周数（周 + 天/7）
- 男胎健康列"否"仅 38 例（3.5%）——问题 3 的"达标比例"可能用 Y≥4% 达标率而非健康标签
- AB 异常 vs 健康全"是"：AB 可能是检测"疑似"，健康是出生后确认——问题 4 以 AB 为标签（题目明确）
- 多次抽血是同一孕妇纵向——问题 2/3 用每孕妇"最早达标孕周"聚合
