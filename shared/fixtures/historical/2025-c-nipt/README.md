## 四问建模要点

- 问题 1：Y 染色体浓度 ~ 孕周 + BMI 线性混合效应（孕妇随机截距）+ 相关分析与显著性检验
- 问题 2：男胎按 BMI K-means 分组 → 各组最佳 NIPT 时点（Y 浓度 ≥4% 最早时间，P90）+ bootstrap 置信区间 → 最小化潜在风险 + 误差影响
- 问题 3：多因素（身高/体重/年龄等）混合效应 → 综合达标比例与误差 → BMI 分组 + 最佳时点
- 问题 4：女胎异常判定（AB 列非整倍体），X 染色体浓度阈值 + 孕妇去重 + 分型，与 Z 值法对比
