# TOPSIS

## 适用问题
多属性决策中比较有限方案的优劣排序，如多方案评价选优、多指标绩效排名。

## 禁用场景
指标权重缺失或主观性过强时需要先确定权重；方案数过少（如 2 个）时排序意义有限；指标含义方向不清时结果无法解释。

## 输入与假设
输入为方案-指标矩阵与权重向量；假设指标可正向化、可比较，权重已知（可由熵权/AHP 提供）。

## 核心公式
向量归一化 rᵢⱼ = xᵢⱼ/√(Σₖxₖⱼ²)；正理想解 Z⁺、负理想解 Z⁻；贴近度 Cᵢ = D⁻/(D⁺+D⁻)，其中 D 为欧氏距离。

## 直观解释
每个方案看它离"最好的想象方案"有多远、离"最差的想象方案"有多近，距离比越接近 1 越优。

## 建模步骤
① 指标正向化并确定权重；② 向量归一化得加权矩阵；③ 找正负理想解；④ 算距离与贴近度并排序。

## 参数选择
权重向量是关键输入（由熵权/AHP 提供）；距离度量默认欧氏距离，指标相关时可换马氏距离。

## 工具入口
主体逻辑用 numpy 实现（矩阵运算），无需专门库；权重获取可配合 sklearn.preprocessing 或 scipy.stats；个别第三方库如 pymcdm 可参考。

## 最小示例
`import numpy as np; R = X / np.sqrt((X**2).sum(axis=0)); V = R * w; dp = np.sqrt(((V - V.max(axis=0))**2).sum(axis=1)); dn = np.sqrt(((V - V.min(axis=0))**2).sum(axis=1)); C = dn / (dp + dn)`。

## 评价指标
排序合理性；贴近度分布（是否过于集中）；与其他评价方法排序的一致性。

## 检验方法
微调权重观察排序稳定性；与熵权加权求和得分排序对比；检查贴近度是否有方案接近 0 或 1 的极端情形。

## 对比基线
基线为简单加权求和法（SAW）；若两者排序差异大，检查是否因指标相关导致欧氏距离失真。

## 替代模型
指标相关时先 PCA 再 TOPSIS 或用马氏距离；群体决策用灰色关联-TOPSIS 组合；评价粒度更粗时用模糊综合评价。

## 常见误用
忘记正向化导致方向相反；用 min-max 归一化代替向量归一化（结果仍可用但需说明）；把贴近度绝对值当"得分"跨任务比较。

## 失效征兆
正负理想解相同导致贴近度全为 1；排序对权重极敏感；贴近度区分度极低（最大值与最小值差小于 0.05）。

## 论文表达示例
"基于熵权法确定权重后采用 TOPSIS 对各方案评价，方案 A 的贴近度为 0.873 居首，显著高于其余方案，故推荐方案 A 为最优。"

## 对应练习
对给定矩阵计算贴近度并排序；改变某一指标权重观察排序变化并讨论稳健性。
