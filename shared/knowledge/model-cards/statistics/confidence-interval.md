# 置信区间

## 适用问题
估计总体参数（均值、比例、回归系数）的可靠范围，量化估计的不确定性，如均值区间、预测区间。

## 禁用场景
样本非随机时区间无意义；分布严重偏态且样本小时正态近似区间失真；把 95% 区间误解为参数落在其中的概率。

## 输入与假设
输入为随机样本与目标参数；假设抽样随机、样本近似正态（或由中心极限定理支持，n 足够大）。

## 核心公式
均值 95% 置信区间 = x̄ ± t_{α/2,n−1}·s/√n；比例区间 = p̂ ± z_{α/2}·√(p̂(1−p̂)/n)；回归系数 β̂ ± t·SE(β̂)。

## 直观解释
反复抽样下，按同样方法构造的区间约有 95% 会覆盖真实参数；区间越窄说明估计越精确。

## 建模步骤
① 确认抽样与分布假设；② 选公式（t/z/bootstrap）；③ 计算点估计、标准误与临界值；④ 报告区间并解读。

## 参数选择
置信水平（90/95/99%）；t 或 z（样本小用 t）；bootstrap 次数（≥1000）用于非正态数据。

## 工具入口
scipy.stats.t.interval、scipy.stats.norm.interval、statsmodels 的 OLS 结果自带 conf_int()；bootstrap 用 numpy 随机抽样。

本工具以生存函数计算靠近 1 的置信水平的上尾临界值，避免 `(1+confidence)/2` 的舍入失真。均值样本真实零方差返回退化区间；极小但非零的浮点方差仍按缩放后的 t 半宽计算。Wilson 区间采用按样本量缩放的闭式公式，以保留超大样本量下的非零概率边界。

## 最小示例
`from scipy import stats; ci = stats.t.interval(0.95, df=n-1, loc=xbar, scale=s/np.sqrt(n))`；回归 `res.conf_int()`。

## 评价指标
区间宽度；覆盖概率（模拟验证）；与点估计的一致性；是否含 0（判断显著性）。

## 检验方法
模拟数据验证覆盖概率接近 95%；bootstrap 与正态近似区间对比；敏感性（剔除极端值）。

## 对比基线
基线为点估计本身；区间过宽说明样本不足，需增大样本或降低置信水平。

## 替代模型
非正态小样本用 bootstrap 百分位区间；比例用 Wilson 区间；贝叶斯用可信区间（含义不同）。

## 常见误用
把"参数有 95% 概率落在区间内"当区间含义；区间不含 0 就断言"效应很大"（看宽度与效应量）；样本不随机仍建区间。

## 失效征兆
区间宽度接近整个量程（信息量极低）；bootstrap 与正态区间差异巨大（分布偏离）；区间与业务常识矛盾。

## 论文表达示例
"样本均值为 12.4，95% 置信区间为 [11.8, 13.0]，区间不含 0 且宽度适中，估计精度满足要求；回归系数 β 的 95% 置信区间为 [0.31, 0.58]，支持其正向显著影响。"

## 对应练习
计算给定样本的均值 95% 置信区间并与 bootstrap 对比；用回归 conf_int 判断系数显著性。
