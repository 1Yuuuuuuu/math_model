# 相关分析

## 适用问题
度量两个或多个变量之间关联的强度与方向，如影响因素初筛、共线性诊断、探索性分析。

## 禁用场景
要证明因果关系时相关不够；变量非线性且单调性不强时皮尔逊相关系数失真；含离群值时相关系数不稳定。

## 输入与假设
输入为成对数值（或等级）数据；皮尔逊假设近似线性与正态；斯皮尔曼仅假设单调关系。

## 核心公式
皮尔逊 r = Σ(xᵢ−x̄)(yᵢ−ȳ)/√(Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²)；斯皮尔曼为秩的皮尔逊；p 值检验 r=0。

## 直观解释
r 接近 1/-1 表示同向/反向强线性关联，接近 0 表示无明显线性关联；相关性只讲"一起变"，不讲"谁导致谁"。

## 建模步骤
① 检查数据分布与离群；② 选皮尔逊或斯皮尔曼；③ 计算相关矩阵与 p 值；④ 可视化（散点/热力图）并解释。

## 参数选择
连续近似正态用皮尔逊；有序/非正态用斯皮尔曼；多重比较时用 Bonferroni/FDR 校正 p 值。

## 工具入口
scipy.stats.pearsonr、scipy.stats.spearmanr、pandas.DataFrame.corr、seaborn.heatmap 可视化。

## 最小示例
`from scipy.stats import pearsonr; r, p = pearsonr(x, y)`；`df.corr(method="spearman")`。

## 评价指标
相关系数与 p 值；相关矩阵的显著项数量；效应量大小分级（|r|≥0.8 为强相关）。

## 检验方法
显著性检验（p<0.05）；bootstrap 置信区间；散点图目视确认无异常点主导。

## 对比基线
基线为 0 相关假设；与灰色关联等其它关联度量对照。

## 替代模型
因果关系用回归/实验设计；非线性关联用灰色关联或互信息；多变量结构用 PCA/因子分析。

## 常见误用
相关高就断言因果；忽略第三个变量；混合不同类型数据算皮尔逊；把弱相关解读为无关系。

## 失效征兆
散点图上一个离群点决定高相关；r 与散点图观感矛盾；p 值显著但 |r|<0.1（样本大导致）。

## 论文表达示例
"皮尔逊相关分析显示 X 与 Y 显著正相关（r=0.72，p<0.001），散点图呈线性递增，初步确认 X 为 Y 的候选影响因素，后续以回归模型量化影响。"

## 对应练习
计算皮尔逊与斯皮尔曼相关并比较差异；构造含离群点的数据观察 r 的敏感性。
