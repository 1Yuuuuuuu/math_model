# 动态规划

## 适用问题
具有最优子结构与重叠子问题的多阶段决策，如最短路径、背包、资源分配、设备更新问题。

## 禁用场景
状态空间爆炸（高维连续状态）时不可行；问题无最优子结构时 DP 不适用；小规模问题直接枚举更简单。

## 输入与假设
输入为阶段、状态、决策与转移方程；假设最优策略的子策略仍最优（最优子结构），状态可枚举。

## 核心公式
递推方程 f(k,s) = min/max{ g(s,d) + f(k+1, T(s,d)) }；背包 f(i,w) = max(f(i−1,w), f(i−1,w−wᵢ)+vᵢ)。

## 直观解释
把大问题拆成一层层小问题，先算最小的、记住结果，往上复用，避免重复计算。

## 建模步骤
① 定义阶段、状态、决策；② 写转移方程与边界；③ 按阶段自底向上填表；④ 回溯构造最优决策序列。

## 参数选择
状态离散化粒度（连续状态离散化时权衡精度与规模）；内存（表大小）与时间权衡；剪枝条件。

## 工具入口
一般手写（numpy 数组做表）；背包可用 numpy 向量化；DP 是算法模式而非现成函数，无专门通用库。

## 最小示例
`import numpy as np; dp = np.zeros((n+1, W+1), dtype=int)`，然后按背包转移方程填表。

## 评价指标
最优值正确性；时间/空间复杂度；与枚举/贪心解对比。

## 检验方法
小规模与暴力枚举对比；边界用例（0 容量、0 物品）；与贪心解对比说明 DP 必要性。

## 对比基线
基线为贪心法或枚举；若贪心已最优（如部分背包），不必用 DP。

## 替代模型
规模大时用启发式/近似算法（遗传、贪心+局部搜索）；连续决策用 NLP；分配问题用匈牙利算法。

## 常见误用
状态定义含混导致重复计算或漏状态；边界初始化错误；用递归不记忆化导致指数爆炸。

## 失效征兆
大规模状态内存溢出；结果与枚举不一致；递推出现循环依赖。

## 论文表达示例
"问题满足最优子结构，建立动态规划递推方程 f(i,w)，自底向上填表求解，时间复杂度 O(nW)，与穷举对比结果一致，得到最优装载方案价值 128。"

## 对应练习
实现 0-1 背包 DP 并与枚举对比；将最短路径问题转化为 DP 递推并求解。
