# 数据类型与清洗

## 是什么
数据类型描述变量的取值性质：数值型（连续或离散）、类别型（无序或有序）、日期时间型、文本型等；清洗是按类型修正数据问题的过程，包括处理缺失、重复、异常、格式不一致与单位不统一。

## 为什么重要
类型决定可用方法：均值只对数值有意义，日期要解析后才能算间隔，类别不能做算术。脏数据会系统性扭曲统计量与模型估计，先弄清类型再清洗是建模的第一步。

## 常见误区
把类别当数值直接计算；用 0 填充缺失后误以为"没有缺失"；忽略重复行虚增样本量；不区分"缺失"与"取值为 0"；日期按字符串处理导致排序错误。

## 在本工作台中的用法
先用 data/profile.py 的 profile_dataframe 审计：报告每列 dtype、缺失数、缺失比例、唯一值与重复行，并检查 key 列唯一性；再按审计结果用 data/transform.py 的 transform_dataframe 配置清洗步骤，如 drop_columns、drop_missing、fill_missing、normalize、to_datetime、cast，先审计后清洗。

## 一句话总结
先识别类型，再按类型清洗，数据才值得进入建模。
